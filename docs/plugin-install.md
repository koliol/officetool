# 桌面插件安装说明（给最终用户）

插件的作用：**在网页里点文件名，直接用本机 Office 打开共享盘上的原文件**，
不用再去资源管理器里找。

## 一、装哪个文件

交付包里有两个 exe，**任选其一即可**：

| 文件 | 大小 | 需要什么 | 什么时候用 |
|---|---|---|---|
| `OfficeToolPlugin-standalone.exe` | 约 65MB | **什么都不用装** | **默认选这个**，双击就能用 |
| `OfficeToolPlugin.exe` | 约 180KB | 需要先装 .NET 8 桌面运行时 | 电脑上已经装过 .NET 8 桌面运行时 |

> 不确定就选 **standalone**。它是自包含的，不依赖任何系统组件，
> 唯一的代价是文件大一点。

## 二、安装（两种方式，任选）

### 方式 A：图形界面（推荐给所有人）

1. 把 exe 拷到本机一个**不会被随手删掉**的位置，例如
   `C:\Users\<你的用户名>\AppData\Local\OfficeTool\`
   （不要放在「下载」文件夹里，清理下载目录会让插件失效）
2. **双击** exe
3. 右下角通知区域出现一个小图标 → 安装完成

首次双击会自动把协议注册到当前用户下，**不需要管理员权限**，公司电脑一般也不会弹 UAC。

### 方式 B：命令行（推荐给 IT 统一部署）

```cmd
:: 注册协议 + 开机自启
OfficeToolPlugin-standalone.exe --install

:: 只清理注册信息（程序文件与配置、日志保留）
OfficeToolPlugin-standalone.exe --uninstall
```

## 三、怎么用

1. 打开网页 `http://<NAS地址>:8080/`
2. 在列表里**点文件名**
3. 浏览器第一次会问「是否允许打开 officetool」→ 勾选「始终允许」→ 确定
4. 文件就在本机 Office 里打开了

如果第 3 步没看到询问，直接双击了也没反应，多半是插件没在运行 ——
看右下角有没有插件图标；没有的话再双击一次 exe。

## 四、托盘图标能做什么

在右下角图标上**右键**：

| 菜单项 | 作用 |
|---|---|
| 打开共享文件夹 | 用资源管理器打开共享盘根目录 |
| 开机自启 | 勾选后每次开机自动运行（`--install` 也会打开它） |
| 重新注册协议 | 插件文件被移动过、或协议被清理时用 |
| 关于 | 显示版本与当前注册状态 |
| 退出 | 关闭插件（协议仍注册着，下次点文件会重新拉起） |

## 五、常见问题

**双击 exe 没反应？**
先看通知区域有没有图标。已经有一个实例在运行时，再次双击只会提示
「已经在运行」，这是正常的（避免出现多个图标）。

**点文件名提示「无法打开文件」？**
说明协议生效了，但文件打不开。按提示检查：
1. 是否连着公司内网（共享盘要能访问）
2. 在资源管理器地址栏粘贴该路径，能不能直接打开
3. 文件是不是被同事重命名/删除了

**「无法识别协议地址」？**
网页给的地址格式不对。正常形如
`officetool://open?path=...`，把这个提示截图发给管理员。

**想彻底卸载？**
1. `OfficeToolPlugin-standalone.exe --uninstall`
2. 删除 exe 文件
3. 删除 `%APPDATA%\OfficeTool\`（配置与日志）

注册信息全在当前用户注册表 `HKEY_CURRENT_USER\Software\Classes\officetool`，
不需要管理员权限即可清除。

**装了没生效，怀疑被安全软件拦了？**
插件只做三件事：读当前用户的注册表协议项、调用系统默认程序打开文件、
在通知区域显示图标。不联网、不访问除共享盘以外的路径。
日志在 `%APPDATA%\OfficeTool\plugin.log`，可以拿给 IT 排查。
